# Environments

Environment roots will compose released PSDC artifacts for local development,
pilot and production without copying their source. Exact state backends,
credentials and production topology remain outside Git or encrypted according to
institution policy.

The [local synthetic Wave A profile](local-synthetic/README.md) is a design-only,
loopback-scoped guardrail for development. It is not a runnable environment or an
institution-approved network/KMS profile.
