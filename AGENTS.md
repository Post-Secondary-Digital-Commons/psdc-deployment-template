# Agent instructions for psdc-deployment-template

The deployment template owns neutral deployment composition and signed manifest structure.

Before assessing or editing this repository, read [the skill manifest](.psdc/agent-skills.yaml) and its pinned common skill policy. Start at [README.md](README.md) and [manifests/README.md](manifests/README.md). Use the PSDC project assessment rubric for readiness claims and the evidence audit for claims about tests or deployment.

Shared decisions and contracts belong to `psdc-architecture`; propose changes there before changing a common interface here. This repository's change scope is its own checkout. Keep institution branding, secrets, topology, and deployment policy in institution overlays. A documentation or schema check supports structural evidence only.
